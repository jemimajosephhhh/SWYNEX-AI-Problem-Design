# AI Resume–Job Match & Skill Gap Analyzer

## SWYNEX Artificial Intelligence Internship – Task 1

### Project Overview

The AI Resume–Job Match & Skill Gap Analyzer is a proposed AI system designed to help students and entry-level job seekers understand how well their technical skills match the requirements of a target job.

The system analyzes a resume and a job description, identifies relevant technical skills, compares the two, and highlights matched and missing skills.

### Problem

Students and job seekers often find it difficult to manually compare their resumes with technical job descriptions. Important skill gaps can easily be overlooked, making it harder to understand what skills need improvement.

### Proposed Solution

The proposed system will use Natural Language Processing (NLP) techniques to:

- Extract technical skills from resumes and job descriptions
- Compare candidate skills with job requirements
- Identify matched and missing skills
- Calculate a simple skill-match percentage
- Provide basic skill-gap recommendations

### Target Users

- College students
- Recent graduates
- Entry-level job seekers
- Candidates applying for technical roles

### Input

The system will accept:

- Candidate resume
- Target job description

### Expected Output

The system will provide:

- Skill-match percentage
- Matched skills
- Missing skills
- Basic skill-gap recommendations

### Evaluation

The proposed system will be evaluated using:

- Precision
- Recall
- F1-score
- Consistency of skill-match results

### Scope

The initial version focuses on technical skills and entry-level technology roles.

Future development may include:

- Experience matching
- Semantic similarity
- Resume improvement suggestions
- Personalized learning recommendations

### Ethical Considerations

The system is intended to provide informational guidance and should not be used as an automated hiring or rejection system.

Sensitive personal attributes should not be used when calculating the skill match.
